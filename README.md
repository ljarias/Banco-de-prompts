# 🤖 Banco de Prompts: ChatGPT como tu Tutor de Programación

¡Bienvenidos al banco colaborativo de prompts para estudiantes de Programación 2 del INEM! 🎓

Estos 7 prompts convierten a ChatGPT en tu tutor personal de programación. Cópialos, pégalos y adáptalos a los temas que estamos viendo en clase, como Python, control de versiones con Git, arreglos o el proyecto de la calculadora.

---

### 1. El plan de 6 semanas 📅
*Primero el camino. Después, a programar.*
> "Actúa como instructor experto de Python y diseñador de planes de aprendizaje. Crea un plan de seis semanas que me lleve desde cero hasta crear una pequeña aplicación funcional. Analiza mi nivel actual, las horas que puedo estudiar por semana, mi objetivo con la aplicación y cómo aprendo mejor. Diseña los temas semanales, lecciones diarias de 40 minutos, ejercicios prácticos, revisiones y las especificaciones del proyecto final."

### 2. Explicador de conceptos 🧠
*Una analogía, un ejemplo y una prueba. Ideal para ciclos, diccionarios o listas.*
> "Actúa como un tutor de programación paciente para principiantes. Explícame este concepto de Python: [concepto]. Analiza lo que probablemente estoy entendiendo mal, la analogía cotidiana que mejor lo explica, el ejemplo de código más sencillo y el error más común de un principiante. Crea una explicación breve, un ejemplo que pueda ejecutar, dos ejercicios y una pregunta para comprobar si lo entendí."

### 3. Detective de errores 🕵️‍♂️
*Que te enseñe a encontrarlo, no solo a corregirlo.*
> "Actúa como un entrenador de depuración que enseña en lugar de solo corregir. Este es mi código y el error que obtengo: [pegar código]. Analiza qué significa el mensaje de error, qué línea lo provoca, por qué falló mi lógica y qué debí comprobar primero. Crea pistas en tres niveles, muestra la solución solo después de las pistas y dame un hábito para evitar este error."

### 4. Ejercicios de práctica 🏋️‍♀️
*Ocho problemas pensados para tus puntos débiles.*
> "Actúa como un entrenador de programación que prepara mi práctica semanal. Crea ejercicios sobre lo que estudié esta semana: [temas]. Analiza mis puntos débiles, los conceptos que omití, los errores de mis últimos intentos y mi ritmo. Diseña ocho problemas de fácil a difícil, una pista para cada uno, el resultado esperado y un problema extra que combine todos los conceptos."

### 5. Mi primera aplicación 🚀
*Un proyecto real que resuelve un problema tuyo (como la calculadora).*
> "Actúa como un mentor que planifica el primer proyecto real de un principiante. Ayúdame a crear una pequeña aplicación en Python que resuelva este problema de mi vida: [problema]. Analiza las funciones que realmente necesita, las bibliotecas que vale la pena usar, los datos que almacenará y lo que puedo desarrollar esta semana. Diseña la estructura de archivos, el orden de desarrollo, las etapas y una prueba para cada función."

### 6. Revisión de código 🧐
*Un senior amable revisando lo que escribiste antes de hacer tu commit.*
> "Actúa como un desarrollador senior amigable que revisa el código de un principiante. Revisa este código: [pegar código]. Analiza la legibilidad, los nombres de variables, el código repetido y lo que podría fallar con más datos. Crea una lista de correcciones por prioridad, una versión más limpia de la peor función, una explicación de cada cambio y un patrón que debería practicar a continuación."

### 7. Mi portafolio 💼
*Tus proyectos, presentados para que te contraten.*
> "Actúa como orientador profesional de tecnología para programadores autodidactas. Convierte mis proyectos terminados en Python en un pequeño portafolio. Analiza el propósito de cada proyecto, las habilidades que demuestra, la calidad del código y lo primero que notaría quien lo revise. Diseña la estructura del archivo de presentación de cada proyecto, un resumen breve, una lista de mejoras y el siguiente proyecto para cubrir mi mayor carencia."

## 🤝 ¿Cómo contribuir a este repositorio? (Colaboración)

Como estamos aprendiendo a utilizar **Git y GitHub**, ¡ustedes mismos pueden mejorar este banco de prompts!

Si encuentras un prompt nuevo que te ayudó a entender un tema difícil, sigue estos pasos para proponer agregarlo:
1. Asegúrate de estar trabajando en tu propio repositorio local.
2. Modifica este archivo `README.md` añadiendo tu prompt.
3. Haz un commit explicando tu aporte: `git commit -m "Agrega nuevo prompt para depurar arreglos"`
4. Sube tus cambios con `git push`.

¡Sigamos construyendo conocimiento juntos! 🚀
