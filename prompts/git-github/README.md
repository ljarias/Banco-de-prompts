# 🌿 Prompts para Git y GitHub

Úsalos para entender lo que ocurre antes de ejecutar comandos que puedan borrar trabajo.

## 1. Explicar git status

> Te voy a copiar la salida de git status. Explícame en español sencillo qué significa cada parte, en qué rama estoy y qué cambios están preparados o pendientes. Después dime cuál sería el siguiente comando más seguro según mi objetivo: [OBJETIVO]. No sugieras comandos destructivos sin explicar primero su efecto.

## 2. Entender un error de Git

> Estoy intentando [OBJETIVO] y Git muestra este mensaje: [ERROR]. Explícame qué significa, cuál es la causa más probable y qué información debería revisar antes de hacer cambios. Dame pasos de diagnóstico desde el más seguro al más invasivo.

## 3. Preparar un buen commit

> Estos son los cambios que hice: [CAMBIOS]. Ayúdame a comprobar si deberían ir en un solo commit o separarse. Propón mensajes de commit cortos que expliquen qué cambió, sin usar mensajes vagos como "cambios" o "actualización".
