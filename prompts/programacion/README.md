# 🐍 Prompts para programación

Pensados para practicar Python y otros lenguajes sin convertir la IA en una máquina de copiar tareas.

## 1. Ejercicios progresivos

> Estoy aprendiendo [TEMAS] en [LENGUAJE]. Diseña 6 ejercicios de dificultad progresiva relacionados con situaciones escolares o cotidianas. Para cada uno indica entrada, proceso esperado y salida. Da una pista, pero no escribas la solución completa. El último ejercicio debe combinar varios conceptos.

## 2. Revisión de código

> Actúa como desarrollador senior que revisa el código de un principiante. Analiza mi código en [LENGUAJE] sin reescribir todo al comienzo. Revisa nombres de variables, repetición, legibilidad, validaciones y posibles errores. Ordena tus observaciones por prioridad. Después muestra únicamente el fragmento que más conviene mejorar y explica cada cambio.

## 3. Dividir un problema en funciones

> Tengo este problema: [PROBLEMA]. Ayúdame a dividirlo en funciones antes de programar. Identifica entradas, procesos y salidas. Propón nombres claros para las funciones, parámetros y valores de retorno. No escribas el programa completo; quiero construirlo paso a paso.
