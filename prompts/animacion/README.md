# 🎞️ Prompts para animación

Para planear movimiento antes de abrir la herramienta de animación.

## 1. Diseñar una secuencia

> Quiero animar [OBJETO O PERSONAJE] haciendo [ACCIÓN]. La animación durará [DURACIÓN] y tendrá [NÚMERO] momentos principales. Divide la acción en poses o estados clave. Explica qué cambia entre uno y otro y qué elementos deben permanecer constantes para que el movimiento se vea continuo.

## 2. Animación educativa

> Necesito explicar [CONCEPTO] mediante una animación corta. Propón una metáfora visual simple, máximo 5 escenas y un texto breve para cada escena. Indica qué aparece, qué se mueve y qué debe entender el espectador antes de pasar a la siguiente.

## 3. Revisar continuidad

> Esta es mi secuencia de animación: [DESCRIPCIÓN DE FRAMES O ESCENAS]. Busca saltos de posición, tamaño, dirección, iluminación o ritmo. Indica exactamente qué elemento pierde continuidad y cómo puedo corregirlo.
