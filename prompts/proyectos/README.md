# 🚀 Prompts para proyectos

Para pasar de una idea grande a tareas pequeñas y comprobables.

## 1. Mi primera aplicación

> Actúa como mentor de un proyecto para principiantes. Quiero crear en [LENGUAJE] una aplicación que resuelva este problema: [PROBLEMA]. Ayúdame a definir una versión mínima que pueda terminar. Identifica funciones, datos necesarios, validaciones, archivos y etapas de desarrollo. Divide el trabajo en incrementos que se puedan probar por separado.

## 2. Proyecto con evidencia de avance

> Este es mi proyecto: [DESCRIPCIÓN]. Crea una lista de hitos pequeños. Para cada hito indica qué debe funcionar, cómo puedo probarlo y qué evidencia puedo guardar en GitHub. Evita agregar funciones que no sean necesarias para la primera versión.

## 3. Mi portafolio

> Actúa como orientador de tecnología. Quiero presentar este proyecto en mi portafolio: [PROYECTO]. Ayúdame a explicar el problema, mi solución, las tecnologías usadas, las decisiones que tomé, las dificultades y lo que aprendí. No inventes funciones que mi proyecto no tenga.
