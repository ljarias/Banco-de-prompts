# 🎬 Prompts para videos

Para convertir una idea en un video corto que pueda grabarse con recursos disponibles.

## 1. De idea a guion

> Quiero crear un video de [DURACIÓN] sobre [TEMA] dirigido a [PÚBLICO]. El video se grabará con [RECURSOS]. Diseña un guion sencillo dividido en inicio, desarrollo y cierre. Para cada parte indica qué se ve, qué se escucha y cuánto tiempo ocupa. Mantén el contenido posible de grabar en un entorno escolar o cotidiano.

## 2. Lista de planos

> Este es mi guion: [GUION]. Convierte el guion en una lista de planos. Para cada plano indica tipo de plano, acción, duración aproximada, audio y transición. Evita movimientos de cámara complicados si puedo resolver la escena con una toma estable.

## 3. Revisar un video antes de grabar

> Revisa esta idea de video: [IDEA]. Detecta partes difíciles de grabar, información que no se entendería solo con imágenes y escenas que podrían simplificarse. Propón alternativas que se puedan realizar con un celular y edición básica.
