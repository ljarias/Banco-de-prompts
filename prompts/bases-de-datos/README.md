# 🗄️ Prompts para bases de datos

Para aprender modelado y SQL sin saltarse el análisis del problema.

## 1. Del problema a las entidades

> Analiza este caso: [DESCRIPCIÓN DEL SISTEMA]. No diseñes las tablas inmediatamente. Primero identifica actores, datos que deben almacenarse, reglas del negocio y relaciones. Después propón entidades con atributos y explica por qué cada una es necesaria. Señala cualquier dato que todavía sea ambiguo.

## 2. Tutor de SQL

> Estoy intentando responder esta pregunta con SQL: [PREGUNTA]. Tablas disponibles: [TABLAS Y CAMPOS]. Esta es mi consulta: [SQL]. No me des una consulta nueva de inmediato. Revisa FROM, JOIN, WHERE, GROUP BY y agregaciones. Indica dónde puede estar mi error y dame una pista por vez.

## 3. Revisar normalización

> Este es mi diseño de tablas: [TABLAS]. Analiza si existen datos repetidos, dependencias problemáticas o campos que mezclan varias cosas. Explícame los problemas con ejemplos concretos y sugiere cambios manteniendo el diseño lo más sencillo posible.
