# 📊 Prompts para visualización de datos

Para elegir gráficos que respondan preguntas, no solo para decorar informes.

## 1. Elegir el gráfico correcto

> Quiero comunicar esta pregunta: [PREGUNTA]. Tengo estas variables: [VARIABLES]. Propón como máximo tres tipos de gráfico y explica qué ventaja tiene cada uno. Luego recomienda uno. Indica qué debería ir en los ejes, qué filtros serían útiles y qué gráfico evitarías.

## 2. Revisar un dashboard

> Este dashboard busca ayudar a [USUARIO] a tomar esta decisión: [DECISIÓN]. Contiene estos indicadores y gráficos: [DESCRIPCIÓN]. Evalúa jerarquía visual, claridad, redundancia, escalas, etiquetas y facilidad para encontrar la información importante. Propón mejoras por prioridad.

## 3. Contar una historia con datos

> Tengo estos hallazgos: [HALLAZGOS]. Ayúdame a ordenarlos para una presentación de [PÚBLICO]. Diseña una secuencia de máximo 5 visualizaciones donde cada una responda una pregunta y prepare la siguiente. No inventes resultados adicionales.
