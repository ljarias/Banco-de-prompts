# 🔎 Prompts para análisis de datos

Para aprender a preguntar a los datos antes de producir conclusiones.

## 1. Plan de análisis exploratorio

> Tengo un conjunto de datos sobre [TEMA] con estas columnas: [COLUMNAS]. Mi objetivo es [OBJETIVO]. Antes de analizar, propón preguntas que sí puedan responderse con estas variables. Después diseña un plan de revisión de calidad, limpieza, estadísticas básicas y relaciones que valga la pena explorar. No inventes columnas que no existen.

## 2. Detectar problemas de calidad

> Estas son las columnas y algunos ejemplos de mis datos: [DATOS]. Ayúdame a detectar valores faltantes, duplicados, formatos inconsistentes, categorías repetidas con diferente escritura y posibles valores atípicos. Para cada problema indica cómo comprobarlo antes de modificar los datos.

## 3. Interpretar resultados

> Obtuve estos resultados: [RESULTADOS]. Ayúdame a interpretarlos sin exagerar. Separa lo que los datos muestran directamente, lo que sería una hipótesis y lo que no puede concluirse con la información disponible.
