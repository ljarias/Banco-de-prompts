# 📷 Prompts para fotografía

Para planear fotografías, analizar composición y aprender a tomar decisiones visuales.

## 1. Crítica fotográfica para aprender

> Actúa como tutor de fotografía. Analiza esta imagen o esta descripción de una foto: [IMAGEN O DESCRIPCIÓN]. Evalúa composición, luz, punto de interés, fondo, color y momento. Señala primero dos cosas que funcionan y luego tres mejoras concretas que pueda intentar en una nueva toma. Explica cada recomendación con lenguaje sencillo.

## 2. Planear una fotografía

> Quiero fotografiar [SUJETO] en [LUGAR O CONTEXTO] usando [CELULAR/CÁMARA]. La luz disponible será [TIPO DE LUZ]. Propón tres ideas de composición, dónde ubicarme, qué debo evitar en el fondo y qué momento sería mejor. Si hablas de ajustes técnicos, explica qué efecto visual producen.

## 3. Fotografía con celular

> Tengo un celular con estas opciones de cámara: [OPCIONES]. Quiero conseguir este resultado: [RESULTADO]. Ayúdame a decidir encuadre, distancia, exposición y uso de luz. Evita recomendar equipos adicionales salvo que sean realmente necesarios.
